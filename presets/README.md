# Community colour presets

The lightbar reads `catalog.json` from the public `prusa-core-one-plus-lightbar-releases` repository. The built-in **Seeq Default** preset is always available in firmware, even without internet access.

The device creates a GitHub issue containing the proposed preset. The publishing workflow validates the schema, colour ranges, duplicate names, allowed characters, and blocked terms before automatically adding it to the catalogue. Invalid submissions are rejected.
