# CORE ONE+ Lightbar firmware releases

This public repository contains compiled firmware binaries for anonymous over-the-air updates, installation guidance, and public support issues. The source code and development history are maintained separately in a private repository.

For fitting and first-time setup, see the [Zeeq CORE ONE Lightbar+ installation guide](INSTALLATION.md). For troubleshooting or support, [open an issue](https://github.com/kelau/prusa-core-one-plus-lightbar-releases/issues).

Firmware binaries are published automatically from the private source build after tests pass. Releases are beta by default and may later be promoted to stable.
